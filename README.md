### Sistema de Gerenciamento de Produtos
Este script implementa um sistema simples de gerenciamento de produtos permitindo: 
- listar, inserir, alterar e excluir produtos (CRUD). 
Obs.: A interação com o sistema ocorre via um menu interativo no terminal.

### Funcionalidades
- `Listar Produtos`: Exibe todos os produtos cadastrados.
- `Inserir Produtos`: Permite adicionar um novo produto fornecendo código, nome, quantidade e valor.
- `Alterar Produtos`: Exibe a lista de produtos e permite alterar a quantidade e o valor de um produto existente.
- `Excluir Produtos`: Exibe a lista de produtos e permite remover um produto da base de dados.
- `Sair`: Encerra o sistema.
